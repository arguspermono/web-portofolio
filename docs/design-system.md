# Design System

## Visual Direction: Minimalist Technical Editorial
Inspired by official Japanese mecha engineering archives (e.g. `gundam-official.com`).

### Core Aesthetic Pillars:
1. **Calm Minimalism**: Remove visual clutter. Let typography, structure, and content stand out through clean whitespace and disciplined 1px panel lines.
2. **Interactive Preview Richness**:
   - In-app modal preview for certificates (document iframe/viewer with pagination).
   - In-app quick modal preview for project specifications and screenshots.
   - Adaptive media container: full portrait mobile framing for MemoSpace; landscape for web apps.
   - Interactive tab controls and copy-to-clipboard actions.
3. **Typography**: Always uppercase for headings, buttons, and navigation with balanced weight (`font-semibold` / `font-bold`).
4. **Color Hierarchy**: High-contrast monochrome (pure `#0A0A0A` and `#FFFFFF`). No harsh artificial contrast filters on photos.
5. **Naming**: Module 03 is officially designated **CERTIFICATES**.
